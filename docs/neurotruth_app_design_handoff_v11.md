# NeuroTruth 모바일 앱 디자인 인계 v11

## 1. 문서 목적

이 문서는 프런트엔드 디자이너가 NeuroTruth 환자용 Android 앱의 화면 구성을 바로 수정할 수 있도록 정리한 화면 중심 인계서다.

- 화면 이미지를 중심으로 설명한다.
- 별도의 서비스 파이프라인이나 백엔드 처리 흐름은 이 문서와 PPT에 넣지 않는다.
- PPT의 화면 이미지는 기존 v7 계열 화면 구조를 보여 주는 참조다.
- 기존 이미지 안의 정확한 퍼센트처럼 변경 전 표현이 남아 있는 경우, 오른쪽 설명과 본 문서의 요구사항을 우선한다.

관련 PPT: `docs/handoff/neurotruth_app_design_handoff_v11.pptx`

## 2. 공통 화면 구조

하단 탭은 다음 세 개만 사용한다.

1. 홈
2. 대시보드
3. 챗봇

설정은 하단 탭에 넣지 않고 홈 우측 상단 버튼으로 연다.

환자 화면에는 서버 주소, 포트, 모델 장치, 내부 오류 코드 같은 개발 정보를 표시하지 않는다.

## 3. 시작 화면

### 제품 안내

- 갈망 상황의 기록과 대화를 돕는 연구용 보조 시스템임을 설명한다.
- 진단·치료·응급 대응을 대체하지 않는다는 한계를 짧게 표시한다.
- `확인하고 계속`을 누르면 가입·로그인 화면을 연다.

### 가입·로그인

- 환자가 직접 가입한다.
- 가입과 기존 계정 로그인을 같은 화면에서 구분한다.
- 인증 전에는 하단 탭을 표시하지 않는다.

### 동의·권한

- 필수 동의와 선택 동의를 구분한다.
- 음성과 카메라는 선택 동의로 관리한다.
- 마이크와 카메라 권한은 실제 기능에 처음 들어갈 때 요청한다.

## 4. 홈

홈은 세 카드와 설정 버튼을 중심으로 구성한다.

### 프로필 카드

- 사용자 이름과 간단한 상태를 표시한다.
- 우측 상단 설정 버튼에서 계정·동의·권한을 관리한다.

### 갈망 상태 카드

정확한 퍼센트 숫자를 환자 화면에 표시하지 않고 다음 네 단계 문구로 표시한다.

| 모델 확률 범위 | 사용자 표시 |
| --- | --- |
| `0 ≤ p < 0.25` | 낮은 가능성 |
| `0.25 ≤ p < 0.50` | 변화 관찰 |
| `0.50 ≤ p < 0.75` | 주의 필요 |
| `0.75 ≤ p ≤ 1.00` | 높은 가능성 |

- 조건이 충족되면 카드 하단에 `얼굴로 측정` 보조 버튼을 표시한다.
- 버튼을 누르면 20초 얼굴 영상 측정 화면을 연다.
- 완료된 카메라 결과는 같은 카드 아래에 별도 결과 카드로 표시할 수 있다.

### Watch 카드

- `연결 필요`, `연결됨`, `20초 수집 중`, `분석 중` 상태를 표시한다.
- 첫 예측 전 최근 20초 PPG/GSR를 수집한다.
- 이후 최신 20초 창을 10초마다 분석한다.
- 홈에는 PPG 파형을 표시하지 않는다.

## 5. 얼굴 영상 측정

화면 상태 문구는 다음 순서로 사용한다.

1. 얼굴 찾는 중
2. 얼굴 안정화
3. 20초 촬영 중
4. 업로드 중
5. 분석 대기
6. 측정 완료 또는 재촬영 필요

- 중앙 얼굴 가이드를 표시한다.
- 얼굴이 1초간 안정적으로 유지되면 촬영을 시작한다.
- 촬영 중 얼굴이 사라지거나 앱이 백그라운드로 이동하면 취소한다.
- 결과는 정확한 확률 숫자보다 네 단계 갈망 상태 문구를 우선한다.

## 6. 갈망 알림과 AUQ

### 갈망 알림

- 스마트폰 팝업 형태로 표시한다.
- `지금 대화하기`와 `나중에`만 제공한다.
- 확정 진단처럼 표현하지 않는다.

### AUQ

- 8문항을 유지한다.
- 사용자는 AUQ를 작성하거나 건너뛰고 대화할 수 있다.
- 각 문항은 숫자가 아니라 다음 문장으로 선택한다.

1. 매우 그렇지 않다
2. 그렇지 않다
3. 조금 그렇지 않다
4. 보통이다
5. 조금 그렇다
6. 그렇다
7. 매우 그렇다

- 결과는 8~56 총점으로 저장한다.
- AUQ 작성 여부가 챗봇 진입을 막지 않는다.

## 7. AI 챗봇

### 입력

- 키보드 입력과 마이크 입력을 함께 제공한다.
- 마이크를 누르면 녹음을 시작하고 다시 누르면 종료한다.
- STT 결과는 입력창에 채우고 사용자가 수정한 뒤 전송한다.
- 음성 인식 결과를 자동 전송하지 않는다.

### AI 응답

- AI 텍스트는 항상 표시한다.
- 각 AI 말풍선에 `듣기`와 `정지`를 제공한다.
- 자동 읽기는 선택 설정이며 기본값은 OFF다.
- TTS가 실패해도 텍스트 대화를 유지한다.

### 대화 방식

- 사용자가 원하는 도움과 상황을 자유롭게 말하는 구조다.
- AI는 공감과 반영을 우선한다.
- 질문은 필요한 경우에만 한 응답당 최대 하나를 사용한다.
- 이미 답했거나 거부한 내용을 다시 묻지 않는다.
- 진단, 처방, 치료효과, 확정적 인과 표현을 사용하지 않는다.

### 재시도와 종료

- 응답 생성에 실패하면 보낸 메시지를 유지하고 `응답 다시 받기`를 제공한다.
- 같은 사용자 메시지를 중복 말풍선으로 만들지 않는다.
- 사용자가 종료하거나 1시간 동안 활동이 없으면 대화를 마감한다.

## 8. 대시보드

대시보드는 날짜 선택, 큰 요약, 그래프, 선택 상세 순서로 세로 스크롤한다.

### 갈망 단계 중첩 막대

- 오늘 24시간을 시간별 막대로 표시한다.
- 한 막대 안에 `낮음 · 관찰 · 주의 · 높음` 표본 비율을 100% 중첩한다.
- 단계별 색상은 모든 기간에서 동일하게 사용한다.
- 막대를 누르면 시간, 단계별 비율, 표본 수를 표시한다.

### 갈망 이벤트

- 실제 알림이 생성된 횟수를 일별 막대로 표시한다.
- 최근 7일과 30일을 전환할 수 있다.
- 데이터가 없는 날과 예측은 있었지만 이벤트가 0건인 날을 구분한다.

### AUQ 기록

- 오늘은 시간별, 7일·30일은 일별로 표시한다.
- `총점 X/56`과 응답 횟수를 표시한다.
- 점수를 임의의 임상 위험 단계로 해석하지 않는다.

## 9. 디자이너 작업 우선순위

### P0

- 홈의 정확한 퍼센트를 네 단계 문구로 교체
- 홈 갈망 카드에 조건부 `얼굴로 측정` 버튼 배치
- 챗봇 입력창에 마이크와 TTS 듣기·정지 배치
- 대시보드 갈망 그래프를 네 단계 중첩 막대로 교체

### P1

- AUQ 문장형 7단계 선택 화면
- 얼굴 측정의 여섯 상태 화면
- 재시도와 1시간 미활동 종료 상태

### P2

- 빈 데이터와 유효한 0건 상태 다듬기
- TalkBack 설명과 색상 외 상태 표기 점검

## 10. 인수 체크리스트

- [ ] 모든 주요 슬라이드에 앱 화면 이미지가 있다.
- [ ] 흐름도와 파이프라인 페이지가 없다.
- [ ] 하단 탭은 홈·대시보드·챗봇 세 개다.
- [ ] 홈에 PPG 파형이 없다.
- [ ] 갈망 상태는 정확한 퍼센트 대신 네 단계 문구다.
- [ ] 얼굴 측정은 20초 촬영 상태를 보여 준다.
- [ ] AUQ는 문장형 7단계다.
- [ ] 챗봇은 텍스트·STT·TTS를 지원한다.
- [ ] 대시보드 갈망 막대는 네 단계 중첩 구조다.
