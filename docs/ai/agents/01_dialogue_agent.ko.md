# 대화 에이전트

최종 업데이트: 2026-07-18

## Endpoint와 책임

`POST /api/sessions/{sessionId}/messages`는 인증된 환자 메시지 하나를 받아 암호화된 user/assistant turn과 conversation ledger를 저장합니다. 신규 session은 `free_dialogue`로 진행하며 slot을 쓰거나 slot coverage field를 반환하지 않습니다.

## 대화 정책

- `free-dialogue-v4-met-cbt-informed`는 MET·CBT 원칙을 치료 프로토콜이 아닌 비임상 대화 태도로 사용합니다.
- 사용자의 자율성, 선택권, 양가감정을 존중하고 설득·논쟁·훈계·낙인을 피합니다.
- 매 턴에는 반영, 양가감정 탐색, 상황-생각-감정/신체-행동-결과 연결, 허락 기반 도움, 사용자 주도 다음 행동 정리 중 하나만 사용합니다.
- 질문은 필요할 때만 최대 하나이며, 고정 문진이나 topic 완료율을 두지 않습니다. 이미 물었거나 거부한 질문은 우회 표현까지 다시 묻지 않습니다.
- 조언이나 대처 방법은 사용자가 도움을 요청하거나 허락한 경우 한 가지만 제안합니다.
- 재음주를 실패로 규정하지 않으며 사용자가 실제로 표현하지 않은 동기·강점·상태를 만들어내지 않습니다.
- 진단, 처방, 수치심 유발, 임상 결과 약속, 즉각적 갈망 감소, 치료 성공, 확실성 또는 인과 효과를 주장하지 않습니다.
- 사용자가 술을 직접 다루게 하는 단서 노출, 임상적 contingency-management protocol, 약물 변경 및 음주량 처방은 제안하지 않습니다.
- 응답은 TTS에 적합한 짧은 한국어 2~5문장으로 생성합니다. 출력 검증 또는 반복 질문 실패 시 repair는 한 번만 수행하며, 이후에는 provider 오류로 처리합니다.

대화 원칙은 이상규의 「알코올 사용장애의 동기강화치료와 인지행동치료」(2019)에 정리된 자율성, 공감, 양가감정 탐색, 자기효능감, 기능분석 및 대처기술 원칙을 비임상적으로 재구성했습니다. 논문은 챗봇 임상 검증이나 대화 매뉴얼이 아니므로 치료 효과를 주장하는 근거로 사용하지 않습니다. 기존 선택형 한국어 question guide `niaaa-samhsa-who-ko-v1`도 참고 자료로만 유지합니다.

## 안전

LLM이 즉각적 신체 위험으로 판단한 경우 119, 자살·자해 문맥에는 109를 일반 대화보다 먼저 안내합니다. 시스템이 신고하거나 전문 대응을 보장하지 못한다고 명시합니다. 이 판단은 연구·데모용 LLM 출력이며 보장된 응급 대응이 아닙니다.

Provider 실패 시 사용자 메시지는 동일 `clientMessageId`로 한 번 재시도할 수 있으며 중복 저장하지 않습니다. 최종 확인된 STT 텍스트와 직접 입력 텍스트는 같은 대화 정책을 사용합니다.
