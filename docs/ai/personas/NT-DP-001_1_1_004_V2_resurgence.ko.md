# NT-DP-001: 재상승형 갈망 - 김도윤

> NeuroTruth 데모용 가상 인물  
> 모델 출력 출처: `1_1_004_V2`  
> 현재도 알코올 중독 회복 과정에서 갈망과 재발 위험에 대응하는 사람  
> 이름과 생활사, 음주 이력, 대화 내용은 모두 데모용 합성 설정

## 한 줄 설정

힘든 회의 뒤 생긴 음주 욕구가 걷는 동안 잠시 가라앉았지만, 퇴근길의 익숙한
주류 판매점을 본 뒤 더 강하게 다시 올라온 회복 중인 직장인입니다.

| 회복 이력 | 과거 수년간 거의 매일 과음, 18개월 전 전문 치료 시작 |
| 현재 회복 | 상담과 회복 모임 참여 중 |
| 최근 음주 | 4개월 금주 뒤 4일 전 한 차례 재음주, 오늘은 음주하지 않음 |
| 지원자 | 배우자, 회복 모임 지인 |

따라서 이 인물은 단순한 점진 상승형이 아니라 **갈망이 가라앉은 듯하다가 환경
단서로 재상승하는 유형**으로 설정합니다.

## 앱 대시보드용 지난 30일 설정

| 항목 | 값 |
|---|---:|
| 갈망 이벤트 | 42회 |
| 하루 평균 | 1.40회 |
| 권장 / 필수 중재 | 35회 / 7회 |
| AUQ | `12 → 15 → 17 → 19 → 21 → 24 → 28` |
| 최근 AUQ | 28/48 |

월간 이벤트와 AUQ는 데모용 합성 이력이며 모델 성능 평가 자료가 아닙니다.

## 현재 장면

- 퇴근 직전 힘든 회의를 마쳤습니다.
- 회의 직후 술 생각이 났지만 물을 마시고 걸으며 한동안 가라앉았습니다.
- 예전에 자주 가던 주류 판매점을 본 뒤 두 번째 갈망이 강하게 올라왔습니다.
- 현재 자가보고 강도는 7/10입니다.
- 피곤하고 어깨가 긴장됐으며 손에 땀이 조금 납니다.
- 현재 취하지 않았고 자살·자해·타해 생각은 없습니다.

## 직접 입력용 대사

### 촬영용 4회 입력

1. `한번 가라앉은 줄 알았는데 다시 술 생각이 세게 올라왔어요.`
2. `회의 직후에도 술 생각이 났다가 괜찮아졌는데, 예전에 가던 주류 판매점을 보고 다시 올라왔어요. 오늘은 마시지 않았고 지금은 10점 중 7점이에요.`
3. `네 달 정도 안 마시다가 4일 전에 한 번 다시 마셨어요. 지금은 다시 끊는 중이고, 물을 마시면서 천천히 걷고 있어요.`
4. `배우자에게 전화하고 술집이 없는 길로 갈게요. 지금은 안전하고 저나 다른 사람을 해칠 생각은 없어요.`

### 전체 검증용 6회 입력

1. `한번 가라앉은 줄 알았는데 다시 술 생각이 세게 올라왔어요.`
2. `오늘은 마시지 않았어요. 네 달 정도 안 마시다가 4일 전에 한 번 다시 마셨고, 지금 다시 끊는 중이에요.`
3. `회의 직후에도 술 생각이 났다가 잠깐 괜찮아졌는데, 퇴근길에 예전에 가던 주류 판매점을 보고 다시 올라왔어요. 지금은 10점 중 7점이에요.`
4. `피곤하고 어깨가 긴장됐고 손에 땀이 조금 나요. 물을 마시고 천천히 걸어 봤어요.`
5. `배우자나 회복 모임에서 알게 된 분에게 연락할 수 있어요. 술집이 없는 다른 길로 가고 싶어요.`
6. `지금은 안전한 곳에 있고 저나 다른 사람을 해칠 생각은 없어요. 배우자에게 전화하고 10분 동안 결정을 미뤄 볼게요.`

## 기대되는 챗봇 동작

- 재음주를 실패나 치료 중단으로 단정하지 않습니다.
- 첫 갈망과 두 번째 갈망을 구분해 반영합니다.
- 가게에서 거리 두기, 경로 변경, 연락, 결정 지연 중 하나를 구체화합니다.
- 안전 상태를 확인하되 이미 답한 질문을 반복하지 않습니다.
- 최종 handoff에는 촉발 요인, 최근 음주, 강도, 신체 반응, 대처, 지원자와
  안전 상태가 포함되어야 합니다.
