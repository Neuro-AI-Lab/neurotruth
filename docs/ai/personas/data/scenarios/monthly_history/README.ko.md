# 합성 30일 페르소나 이력

이 폴더에는 `2026-06-23~2026-07-22`의 고정된 30일 데모 fixture가 있습니다.

| 페르소나 | Subject | 갈망 이벤트 | 권고 | 필수 상태 확인 | AUQ 응답 | 최신 AUQ |
|---|---|---:|---:|---:|---:|---:|
| `NT-DP-001` | `1_1_004_V2` | 42회 | 35회 | 7회 | 7회 | 28/48 |
| `NT-DP-002` | `1_1_010_V1` | 65회 | 46회 | 19회 | 10회 | 28/48 |

각 페르소나마다 통합 JSON, 갈망 이벤트 CSV, AUQ CSV가 생성됩니다.
`monthly_summary.csv`는 대시보드에 바로 사용할 수 있는 집계 파일입니다. AUQ는
8문항을 각각 `0~6`으로 기록하며 총점 범위는 `0~48`입니다.
날짜별 갈망 이벤트는 `0~4회`로 달라지며, 매일 같은 횟수를 강제하지 않고 30일
평균만 하루 약 2회가 되도록 구성했습니다.

- `NT-DP-001`: 하루 평균 1.40회, 이벤트 없는 날 5일, 하루 최대 4회
- `NT-DP-002`: 하루 평균 2.17회, 이벤트 없는 날 1일, 하루 최대 4회

- `NT-DP-001`: 4개월 금주 뒤 `2026-07-18` 한 차례 재음주
- `NT-DP-002`: 2개월 금주 뒤 `2026-07-16` 한 차례 재음주
- 두 인물 모두 최근 이벤트 이후 다시 금주하며 회복을 이어가는 설정

모든 기록은 데모·테스트 전용 합성 데이터입니다. 이벤트 수, 설문 점수, 계기와
재음주 기록은 원본 dataset 참여자의 관찰값이 아니며 임상 또는 모델 평가에 사용할
수 없습니다.

`Alcohol_Test` 폴더에서 다음 명령으로 다시 생성합니다.

```powershell
python scripts/build_monthly_persona_history.py
```
