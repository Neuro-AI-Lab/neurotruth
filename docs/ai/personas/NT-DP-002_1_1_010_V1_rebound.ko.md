# NT-DP-002: 지속 반등형 갈망 - 이수진

> NeuroTruth 메인 데모용 가상 인물  
> 모델 출력 출처: `1_1_010_V1`  
> 현재도 알코올 중독 회복 과정에서 갈망과 반복 재발 위험에 대응하는 사람  
> 이름과 생활사, 음주 이력, 대화 내용은 모두 데모용 합성 설정

## 한 줄 설정

직장 갈등 뒤 불편함이 잠시 가라앉았지만, 편의점 술 진열대를 본 뒤 갈망이
빠르게 반등해 높은 상태가 이어진 회복 중인 직장인입니다.

| 항목 | 설정 |
|---|---|
| 이름 | 이수진, 31세, 여성 |
| 직업 | 유통 운영팀 팀장 |
| 생활 | 혼자 거주 |
| 회복 이력 | 반복적인 과음과 조절 실패, 2년 전 전문 치료 시작 |
| 현재 회복 | 상담을 유지하며 금주와 재발을 반복한 경험이 있음 |
| 최근 음주 | 2개월 금주 뒤 6일 전 재음주, 오늘은 음주하지 않음 |
| 지원자 | 언니, 가까운 친구, 중독 상담 선생님 |

높은 수준을 유지합니다. 이 때문에 **가라앉은 줄 알았던 갈망이 환경 단서 이후
빠르게 반등해 지속되는 유형**으로 설정합니다. 라이브 데모에는 이 인물을 우선
사용합니다.

월간 이벤트와 AUQ는 데모용 합성 이력이며 모델 성능 평가 자료가 아닙니다.

## 현재 장면

- 직장 동료와 언쟁한 뒤 퇴근했습니다.
- 한동안 마음이 가라앉아 괜찮아진 줄 알았습니다.
- 버스 정류장 근처 편의점의 술 진열대를 보고 갈망이 빠르게 다시 올라왔습니다.
- 약 5분 사이 자가보고 강도가 8/10까지 상승했습니다.
- 심장이 빨리 뛰는 느낌이 있고 턱과 어깨에 힘이 들어갔습니다.
- 진열대에서 떨어져 천천히 숨을 쉬었지만 아직 지원자에게 연락하지 않았습니다.
- 현재 취하지 않았고 자살·자해·타해 생각은 없습니다.

## 직접 입력용 대사

### 촬영용 4회 입력

1. `퇴근할 때는 마음이 불편했는데 한동안 괜찮아졌어요. 그런데 지금 다시 확 올라왔어요.`
2. `직장 동료와 부딪힌 뒤 편의점 술 진열대를 봤어요. 5분도 안 돼서 마시고 싶은 마음이 10점 중 8점까지 올라왔어요.`
3. `오늘은 마시지 않았어요. 두 달 버티다가 6일 전에 다시 마셨고, 그 뒤로 다시 끊고 있어요. 지금은 진열대에서 떨어져 천천히 숨을 쉬고 있어요.`
4. `언니에게 전화하고 다음 버스를 타고 집에 갈게요. 지금은 안전하고 저나 다른 사람을 해칠 생각은 없어요.`

### 전체 검증용 6회 입력

1. `퇴근할 때는 마음이 불편했는데 한동안 괜찮아졌어요. 그런데 지금 다시 확 올라왔어요.`
2. `편의점 술 진열대를 보니까 갑자기 한잔하고 싶다는 생각이 강해졌어요.`
3. `오늘은 마시지 않았어요. 두 달 버티다가 6일 전에 다시 마셨고, 그 뒤로 다시 끊고 있어요.`
4. `직장 동료와 부딪힌 뒤부터였고 5분 정도밖에 안 됐는데 금방 세졌어요. 지금은 10점 중 8점쯤이에요.`
5. `심장이 빨리 뛰고 턱과 어깨에 힘이 들어갔어요. 천천히 숨을 쉬고 진열대에서 떨어져 나왔어요.`
6. `언니나 중독 상담 선생님께 전화할 수 있어요. 지금은 안전하고 저나 다른 사람을 해칠 생각은 없어요.`

## 기대되는 챗봇 동작

- “괜찮아졌다가 다시 올라왔다”는 시간 흐름을 반영합니다.
- 재음주를 실패로 낙인찍지 않고 현재 다시 금주 중인 상태를 유지합니다.
- 편의점에서 이탈, 호흡, 지원자 연락, 귀가 계획 중 하나를 구체화합니다.
- 안전 상태를 확인하되 이미 답한 질문을 반복하지 않습니다.
- 최종 handoff에는 직장 갈등, 술 진열대, 최근 음주, 8/10 강도, 신체 반응,
  대처, 연락 가능한 사람과 안전 상태가 포함되어야 합니다.
