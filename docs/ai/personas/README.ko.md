# NeuroTruth 데모 페르소나

실제 모델 곡선의 형태를 시간축만 60분으로 정규화하고, 그 패턴에 맞춰 만든 가상
인물 2명입니다. 실제 연구 subject에서는 class 1 softmax 값과 순서만 사용합니다.
이름, 생활사, 음주 이력, 월간 이벤트, AUQ와 대화는 모두 데모용 합성 설정입니다.

| 역할 | 페르소나 | 실제 곡선 형태 | 문서 |
|---|---|---|---|
| 메인 라이브 데모 | `NT-DP-002 / 1_1_010_V1` | 깊은 저점 뒤 급반등, 높은 상태 지속 | [이수진](NT-DP-002_1_1_010_V1_rebound.ko.md) |
| 보조·대시보드 데모 | `NT-DP-001 / 1_1_004_V2` | 높은 구간 뒤 완화, 후반 재상승 | [김도윤](NT-DP-001_1_1_004_V2_resurgence.ko.md) |

촬영 중 입력할 문장만 보려면 [운영자 입력 대본](DEMO_OPERATOR_SCRIPT.ko.md)을
사용합니다.
[페르소나 데이터 안내서](data/README.ko.md)에서 Git에 포함된 전체 데이터 묶음과
파일별 성격을 확인할 수 있습니다.

## 데이터 경계

- 원본 window: `1_1_004_V2` 149개, `1_1_010_V1` 113개
- 1시간 변환: 원본 MA10 계산 후 값과 순서를 보존한 시간축 정규화
- 사용하지 않는 변환: 임의 상승 keyframe, 두 subject 연결, 임의 확률 생성
- 월간 이력과 AUQ: 페르소나를 위한 합성 데이터
- 목적: 앱 동선, 챗봇, slot, handoff와 대시보드 데모
- 비목적: 모델 정확도, 임상 진단 또는 중재 효과 증명
