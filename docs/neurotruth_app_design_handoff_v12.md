# NeuroTruth 모바일 프런트엔드 통합 인계 v12

## 1. 목적

이 문서는 화면 디자인과 앱 내부 이동을 하나의 인계 자료로 묶는다.

- 슬라이드 1: 전체 사용자 흐름
- 슬라이드 2~6: 화면 이미지와 디자인 요구사항
- 슬라이드 7~9: 버튼, 앱 반응, 이동·유지 화면 파이프라인

관련 PPT: `docs/handoff/neurotruth_app_design_handoff_v12.pptx`

## 2. 공통 구조

- 하단 탭: `홈 · 대시보드 · 챗봇`
- 설정: 홈 우측 상단
- 홈: 프로필, 갈망 상태, Watch 상태
- 홈 갈망 카드: 조건 충족 시 `얼굴로 측정`
- 홈에는 PPG 파형을 표시하지 않는다.
- 환자 UI에는 서버 주소, 포트, 모델 장치와 내부 오류 코드를 표시하지 않는다.

## 3. 화면 요구사항

### 시작·가입·동의

- 제품 안내 후 환자가 직접 가입하거나 로그인한다.
- 필수 동의와 선택 동의를 구분한다.
- 음성과 카메라는 선택 동의로 관리한다.
- 마이크·카메라 권한은 실제 기능을 처음 열 때 요청한다.

### 홈

- 프로필 카드에서 사용자 요약을 표시한다.
- 갈망 상태는 정확한 퍼센트 대신 네 단계 문구로 표시한다.

| class-1 확률 | 사용자 문구 |
| --- | --- |
| `0 ≤ p < 0.25` | 낮은 가능성 |
| `0.25 ≤ p < 0.50` | 변화 관찰 |
| `0.50 ≤ p < 0.75` | 주의 필요 |
| `0.75 ≤ p ≤ 1.00` | 높은 가능성 |

- Watch는 `연결 필요`, `연결됨`, `20초 수집 중`, `분석 중` 상태를 사용한다.
- 첫 20초 수집 후 최신 20초 창을 10초마다 분석한다.
- 얼굴 측정은 20초 촬영 후 업로드·분석 상태를 표시한다.

### 알림과 AUQ

- 알림은 `지금 대화하기`와 `나중에`를 제공한다.
- `지금 대화하기` 뒤 AUQ를 작성하거나 건너뛸 수 있다.
- AUQ는 8문항이며 다음 문장형 7단계를 사용한다.

1. 매우 그렇지 않다
2. 그렇지 않다
3. 조금 그렇지 않다
4. 보통이다
5. 조금 그렇다
6. 그렇다
7. 매우 그렇다

- 총점은 8~56으로 저장하며 AUQ가 대화를 차단하지 않는다.

### 챗봇

- 텍스트 입력과 마이크 STT 입력을 함께 제공한다.
- STT 결과는 입력창에 채우고 사용자가 편집 후 전송한다.
- AI는 공감과 반영을 우선하고 필요한 경우에만 질문 하나를 사용한다.
- 이미 답했거나 거부한 내용을 반복 질문하지 않는다.
- AI 텍스트는 항상 표시하고 말풍선별 TTS 듣기·정지를 제공한다.
- 실패 시 보낸 메시지를 유지하고 응답만 다시 받는다.
- 수동 종료 또는 1시간 미활동으로 대화를 마감한다.

### 대시보드

- 오늘 24시간 갈망 상태는 네 단계 비율을 한 막대에 중첩한다.
- 막대 선택 시 단계별 비율과 표본 수를 표시한다.
- 갈망 이벤트는 실제 알림 생성 횟수를 일별 막대로 표시한다.
- 데이터가 없는 날과 예측은 있었지만 이벤트가 0건인 날을 구분한다.
- AUQ는 `총점 X/56`과 응답 횟수를 표시한다.

## 4. 파이프라인 1 — 시작·홈·측정

| 누르는 항목 | 앱 반응 | 이동·유지 화면 |
| --- | --- | --- |
| 확인하고 계속 | 제품 안내 확인 상태 저장 | 가입·로그인 |
| 가입하고 시작 / 로그인 | 계정 처리 후 필요한 동의 상태 확인 | 동의 또는 홈 |
| 저장하고 홈으로 | 선택 동의와 권한 상태 저장 | 홈 |
| 설정 | 계정·동의·권한 관리 화면 표시 | 설정 |
| Watch 연결 | 20초 수집 후 10초마다 최신 창 분석 | 홈 유지 |
| 얼굴로 측정 | 얼굴 안정화 후 20초 촬영·업로드·분석 | 얼굴 측정 후 홈/대시보드 |

## 5. 파이프라인 2 — 알림·AUQ·대화

| 누르는 항목 | 앱 반응 | 이동·유지 화면 |
| --- | --- | --- |
| 지금 대화하기 | 대화 시작 선택 저장 | AUQ |
| 나중에 | 알림 닫기 | 현재 화면 유지 |
| 7단계 문장 선택 → 다음 | 1~7 값 저장 후 다음 문항 표시 | AUQ 유지 |
| 건너뛰기 / 마지막 완료 | AUQ 상태 저장 | 챗봇 |

## 6. 파이프라인 3 — 음성·텍스트 대화와 기록

| 누르는 항목 | 앱 반응 | 이동·유지 화면 |
| --- | --- | --- |
| 챗봇 탭 | 진행 중 대화를 재개하거나 새 대화 시작 | 챗봇 |
| 마이크 시작 → 정지 | STT 문장을 입력창에 채움 | 편집 상태 유지 |
| 전송 | 최종 사용자 문장 저장 후 AI 응답 요청 | 챗봇 응답 |
| 듣기 / 정지 | Android TTS 재생 상태 전환 | 챗봇 유지 |
| 응답 다시 받기 | 사용자 메시지는 유지하고 응답만 재요청 | 챗봇 유지 |
| 종료 | 대화 마감 후 기록 반영 | 대시보드 확인 가능 |
| 대시보드 막대 선택 | 갈망 단계 비율·AUQ·이벤트 상세 표시 | 대시보드 유지 |

## 7. 프런트엔드 우선순위

### P0

- 홈의 갈망 퍼센트를 네 단계 문구로 교체
- 조건부 `얼굴로 측정` 버튼 배치
- 챗봇 마이크·텍스트 입력과 TTS 듣기·정지
- 대시보드 네 단계 중첩 막대

### P1

- AUQ 문장형 7단계
- 얼굴 측정 상태 화면
- 재시도와 1시간 미활동 종료

### P2

- 빈 데이터와 유효한 0건 구분
- 접근성 라벨과 색상 외 상태 표현

## 8. 인수 체크리스트

- [ ] 앱 화면 이미지와 상세 파이프라인이 모두 제공된다.
- [ ] 하단 탭은 홈·대시보드·챗봇 세 개다.
- [ ] 홈에는 PPG 파형이 없다.
- [ ] 갈망 상태는 네 단계 문구다.
- [ ] Watch와 얼굴 측정은 20초 입력을 사용한다.
- [ ] AUQ는 8문항·문장형 7단계다.
- [ ] 챗봇은 텍스트·STT·TTS를 제공한다.
