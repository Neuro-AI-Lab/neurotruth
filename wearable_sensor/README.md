# GitHub Release Folder

GitHub에 올릴 실제 Android 프로젝트는 아래 폴더입니다.

```text
github_release/HealthSensorApp
```

`github_release` 자체가 아니라 `HealthSensorApp` 폴더 내용을 새 GitHub repository의 루트로 올리면 됩니다.

공개 배포본에서는 로컬 빌드 산출물, `local.properties`, IDE 상태 파일, Samsung SDK AAR 바이너리를 제외했습니다. 자세한 사용법은 `HealthSensorApp/README.md`를 확인하세요.
