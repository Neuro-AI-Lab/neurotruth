# Samsung Health Sensor SDK AAR

이 폴더에는 Samsung Health Sensor SDK AAR 파일을 직접 넣어야 합니다.

공개 GitHub 배포본에는 Samsung SDK 바이너리를 포함하지 않습니다.
Samsung Developer에서 SDK를 받은 뒤 아래 파일명이 되도록 복사하세요.

```text
wearos/libs/samsung-health-sensor-api-1.4.1.aar
```

`wearos/build.gradle`은 이 폴더의 `*.aar`, `*.jar` 파일을 로컬 dependency로 읽습니다.
